Actual tool contract, from `Assets/CoreAIMods/Runtime/LuaExecution/LuaModsLlmTool.cs`:

```text
manage_mods
action: list | get_source | load | reload | unload | export | import | forget | versions | revert | diagnostics
mod_id: string
code: string
bundle: string
revision: integer
keep_objects: boolean = false

ExecuteAsync(string action, string mod_id = null, string code = null,
             string bundle = null, int revision = -1,
             CancellationToken cancellationToken = default, bool keep_objects = false)
```

`load` installs a named persistent mod; `get_source` reads before editing; `reload` keeps its granted capabilities. With default `keep_objects=false`, reload replaces old startup-built objects rather than stacking duplicates. `unload` leaves persisted source dormant; **forget unloads and deletes that exact mod's persisted source/state**. Those distinctions govern the cleanup below.
