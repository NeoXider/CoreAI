## Design and verification status

- Repeat lowering retains the original repeat/until and replaces continue with a jump to a reserved label before until. A suffix beginning at the first direct body local declared after the earliest continue is wrapped in a do block. Valid Luau conditions cannot refer to such skipped locals; earlier locals remain visible. Per-iteration late-local closures keep distinct cells. Invalid Luau semantic programs are outside this subset's validation guarantee.
- Public API: immutable `LuauDownlevelOptions(maxInputCharacters = 1048576, maxOutputCharacters = 4194304, maxEdits = 262144, maxWorkUnits = 16777216, trustedIteratorResolverName = null)` and `Process(string, string, LuauDownlevelOptions)`. Existing Process overloads use the same defaults. Invalid options/refusal return original input plus Error. Counts are UTF-16 characters and deterministic charged operations, not exact heap/time limits.
- `TrustedIteratorResolverName` must be a simple ASCII Lua identifier outside the reserved __luau_t prefix. Generic-for captures it before author locals and passes the original expression list once. The resolver must preserve normal iterator triples and normalize direct table/userdata actual __iter semantics without exposing metatables. Root selected framework name `__coreai_luau_iter`; gate/environment integration is owned outside this lease.
- Floor division and interpolation capture math.floor/tostring hygienically at chunk entry. Prelude edits sort before generated statement wrappers at the same source offset; unsupported-if-expression rollback restores helper state and budget accounting.
- Lexer consumes complete whitespace/newline and Unicode escapes before interpolation-brace detection. Unicode conversion is shared with literal backtick segments; oversized/malformed escapes fail in original coordinates. Unicode policy is 1–16 hex digits and numeric value 0..0x10FFFF, preserving existing byte encoding of surrogate values. The current [official Luau lexer](https://raw.githubusercontent.com/luau-lang/luau/master/Ast/src/Lexer.cpp) also encodes those values and can itself wrap a wide unsigned accumulator; this fix is explicit validation hardening, not a claim of strict upstream rejection.

- Unity, player, IL2CPP, WebGL, device, performance and native-stack gates remain unverified.
