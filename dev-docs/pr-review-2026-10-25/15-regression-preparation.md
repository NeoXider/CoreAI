# PR regression preparation

Status: source artifacts frozen for root review. The frozen reports 01-05 were read before writing. Baseline under test: `bc3fd74f0a889bfe1b1e7babc6bc02ed48a7c05e`. This task writes staged C# fixtures only in `artifacts/pr-review-20261025/regressions/`; no fixture is imported into Unity or executed here.

## Goal and constraints

Prepare assertion-failing regressions for the eight source-confirmed findings using production public paths and existing fixture patterns. Keep the tests unchanged through the later fixes. Scope is exactly three staged C# files and this document. Root owns import, compilation, execution, repairs, Git and publication. No runtime/test source, assets, metadata, scenes, prefabs, shared plans or frozen audit reports may change.

The fixtures must preserve actor isolation, explicit disabled-tool behavior, truthful persistence refusal, writable/verifiable audit progress, Unicode validity, cancellation and exact legacy reflection signatures. They must compile against the current candidate; a missing old API is asserted through reflection rather than referenced by an uncompilable method group. Fixture-owned Unity objects are created before awaits and destroyed only in main-thread teardown. No worker threads or blocking async waits are introduced.

## Reuse decision

Reuse the repository's scoped memory stores, deterministic fake LLM/orchestration seams, virtual idle clock, real tool policy/publisher/interceptor pipeline, summary persistence confirmation callback, audit writer options/verifier and Lua log public API. Existing fixture helpers will be referenced where public; narrow private test stubs may be copied into the staged fixtures. No new runtime seam or guessed fix API is introduced.

## Integration and remaining seam limits

- Import the unchanged files into the existing `CoreAI.Tests` EditMode assembly only after root authorizes integration following all original audits. That assembly already references Core, Source, Mods, MEAI, NUnit and UniTask and has the required existing test-friend access. `COREAI_LLM` is required for tool-binding and native audit-loop cases; the remaining cases do not claim a no-LLM provider proof.
- No ScriptableObject or GameObject is created by these fixtures. Configuration uses plain `CoreAISettingsOptions`. The real audit writer is created on the main thread before the tool await, and the test preserves Unity's synchronization context; its owned writers are disposed in teardown. No `Task.Run`, `Thread`, blocking wait, synchronization-context removal, or `Assert.ThrowsAsync` is added. The production writer may use its existing native worker; its WebGL branch remains the production threadless branch.
- The Source `FileAgentMemoryStore` read-migration failure cannot be isolated as a false-arming Unity EditMode test with its current seam: it calls static `CoreAiWebGlPersistence`, which always returns true under `UNITY_EDITOR`, and exposes no injectable refusal callback. This preparation does not invent one. The summary-store hook tests cover the confirmed read/migration receipt join; a real WebGL run with automatic persistence unarmed or a separately authorized seam is still needed for that Source adapter branch.
- The audit baseline Mono comparison receipt was read (`audit-surrogate-mono-comparison.txt`): baseline replacement write succeeded and explicit strict write threw. This supports the target selection; it is not execution evidence for the new full-pipeline fixture.
- The core exact-arity constructor check is included with the same public compatibility invariant as the host signatures: the current PR also appended its optional scope argument to that constructor. The underlying omitted-provider behavioral tests remain separate from signature presence.
